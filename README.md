# MKD Late Fee — калькулятор пеней для ЖКХ

Калькулятор пеней за просрочку оплаты жилищно-коммунальных услуг.

Приложение позволяет загрузить данные о начислениях и оплатах из Excel, автоматически распределить поступившие платежи и рассчитать пени за каждый период просрочки.

Все данные обрабатываются непосредственно в браузере и никуда не отправляются.

## Возможности

- загрузка начислений и оплат из `.xlsx`;
- автоматическое распределение оплат по задолженности;
- расчет количества дней просрочки;
- расчет пеней по ставкам `1/300` и `1/130`;
- учет мораториев 2020 и 2022 годов;
- учет изменений ключевой ставки Банка России;
- проверка исходных данных и возможных дубликатов;
- формирование подробного расчета в Excel;
- формирование досудебной претензии в Word;
- подготовка документов для печати и сохранения в PDF.

## Формат исходных данных

Приложение принимает файл Excel (`.xlsx`).

Если в книге есть лист **«Данные проекта»**, данные загружаются из него. В противном случае используется первый лист.

| Колонка | Данные |
| --- | --- |
| A | Сумма начисления |
| B | Срок оплаты |
| C | Сумма оплаты |
| D | Дата оплаты |

Начисления и оплаты могут находиться в разных строках.

После загрузки приложение проверяет данные и сообщает о найденных проблемах — например, некорректных датах или возможных повторных начислениях.

## Как рассчитываются пени

Оплаты последовательно распределяются на наиболее ранние обязательства, срок оплаты которых уже наступил.

Для каждой части задолженности отдельно определяется период просрочки.

При расчете применяются:

- с 31-го по 90-й день просрочки — `1/300`;
- с 91-го дня просрочки — `1/130`.

Расчет учитывает изменение ключевой ставки Банка России в течение периода задолженности.

Также предусмотрен учет периодов моратория:

- **06.04.2020–31.12.2020**;
- **01.04.2022–30.09.2022** — для обязательств со сроком оплаты до 01.04.2022.

## Результат

После расчета можно получить:

- общую сумму задолженности;
- сумму начисленных пеней;
- подробную разбивку расчета по периодам;
- Excel-файл с расчетом;
- досудебную претензию в Word;
- версии документов для печати или сохранения в PDF.

## Важно

Калькулятор предназначен для автоматизации расчета и не заменяет проверку исходных данных и полученного результата.

Перед использованием расчета рекомендуется проверить начисления и оплаты, сроки исполнения обязательств, применимость мораториев, ключевую ставку и срок исковой давности.
