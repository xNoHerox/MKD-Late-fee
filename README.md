# MKD Late Fee

Калькулятор пеней за просрочку оплаты ЖКУ.

Работает полностью в браузере: загруженный Excel-файл обрабатывается локально и не отправляется на сервер.

## Возможности

- импорт начислений и оплат из `.xlsx`;
- проверка дат, сумм и возможных дубликатов;
- распределение оплат на наиболее ранние обязательства;
- расчет пеней по периодам `1/300` и `1/130`;
- учет мораториев 2020 и 2022 годов;
- встроенный справочник ключевой ставки Банка России;
- формирование подробного расчета в `.xlsx`;
- формирование досудебной претензии в `.docx`;
- подготовка расчета и претензии к печати или сохранению в PDF.

## Использование

Откройте сайт и загрузите `.xlsx` с исходными данными.

Приложение ищет лист **«Данные проекта»**. Если такого листа нет, используется первый лист книги.

Данные читаются из колонок:

| Колонка | Содержимое |
| --- | --- |
| A | Сумма начисления |
| B | Установленный срок оплаты |
| C | Сумма оплаты |
| D | Дата оплаты |

Начисления и оплаты могут находиться в разных строках.

После загрузки приложение покажет найденные данные и замечания. Исправленные даты и возможные повторные начисления требуют подтверждения перед расчетом.

Затем необходимо выбрать дату расчета и применимые условия моратория.

После успешной проверки можно:

- скачать подробный расчет в Excel;
- скачать досудебную претензию в Word;
- открыть расчет или претензию в печатном виде и сохранить их в PDF средствами браузера.

## Расчет

Оплаты последовательно распределяются на наиболее ранние обязательства, срок оплаты которых уже наступил.

Для каждой части задолженности отдельно определяется период просрочки и рассчитываются пени.

Используются периоды:

- с 31-го по 90-й день просрочки — `1/300`;
- с 91-го дня — `1/130`.

Приложение также умеет исключать из расчета периоды мораториев:

- 06.04.2020–31.12.2020;
- 01.04.2022–30.09.2022 для обязательств со сроком оплаты до 01.04.2022.

Предоплата, которую невозможно распределить на уже наступившие обязательства, считается ошибкой и требует ручной проверки.

## Ключевая ставка

Справочник ставок находится в [`rates.mjs`](rates.mjs).

Встроенные ставки проверены по **24.09.2026**.

При необходимости справочник можно дополнить непосредственно в интерфейсе и указать дату, по которую ставки были проверены.

Расчет блокируется, если выбранная дата выходит за пределы подтвержденного справочника ставок.

> Правила расчета после 2026 года в текущей версии не поддерживаются и требуют обновления расчетной логики.

Актуальную ключевую ставку необходимо сверять с официальными данными Банка России.

## Запуск локально

Проект не требует сборки и внешнего backend-сервера.

Из-за использования ES-модулей удобнее запускать его через любой локальный HTTP-сервер, например:

```bash
python -m http.server 8000
```

После этого откройте:

```text
http://localhost:8000
```

## Тесты

Для проверки расчетной логики нужен Node.js.

```bash
npm test
```

Тесты проверяют:

- календарные границы периодов просрочки;
- исключение периодов мораториев;
- распределение частичной оплаты;
- обработку дубликатов и исправленных дат.

## Публикация на GitHub Pages

Проект можно публиковать напрямую через GitHub Pages — сборка не требуется.

В настройках репозитория откройте:

**Settings → Pages → Build and deployment**

и выберите:

- **Source:** Deploy from a branch
- **Branch:** `main`
- **Folder:** `/(root)`

После публикации приложение будет доступно по адресу GitHub Pages репозитория.

## Конфиденциальность

Обработка Excel-файла выполняется непосредственно в браузере пользователя.

Исходный файл с начислениями и оплатами не загружается на сервер приложением.

Тем не менее не следует добавлять файлы с персональными данными должников непосредственно в публичный GitHub-репозиторий.

## Важно

Калькулятор автоматизирует расчет, но не заменяет юридическую проверку исходных данных.

Перед использованием сформированных документов рекомендуется проверить:

- начисления и оплаты по первичным документам;
- корректность сроков оплаты;
- применимость мораториев;
- актуальность ключевой ставки;
- исковую давность;
- итоговый расчет.
