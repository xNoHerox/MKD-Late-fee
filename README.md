# Расчет пеней за ЖКУ

Сайт для GitHub Pages. Исходный Excel обрабатывается в браузере и не отправляется на сервер.

## Публикация

1. Распакуйте архив. Создайте репозиторий на GitHub и поместите **содержимое папки `peni-pages`**, а не сам ZIP-файл, в корень репозитория. Файл `index.html` должен лежать прямо в корне. Не добавляйте файлы с персональными данными должников.
2. В настройках репозитория откройте **Pages → Build and deployment**. Выберите **Deploy from a branch**, ветку **main** и папку **/(root)**, затем сохраните.
3. После публикации GitHub покажет адрес сайта. Для проекта он обычно имеет вид `https://ИМЯ.github.io/РЕПОЗИТОРИЙ/`.

## Использование

Исходный `.xlsx` должен содержать на листе «Данные проекта» (или первом листе) колонки A–D: сумма начисления, установленный срок оплаты, сумма оплаты, дата оплаты. Начисления и оплаты могут находиться в разных строках. После загрузки проверьте исправленные даты и возможные дубли, затем выберите условия моратория.

Кнопки формируют подробный `.xlsx`, редактируемую досудебную претензию `.docx` и печатные версии документов. Для PDF выберите **Открыть для печати / PDF**, затем в окне браузера — **Сохранить как PDF**.

Ставки Банка России находятся в `rates.mjs`. Встроенный список проверен по 24.09.2026. Для последующих дат сначала сверьте ставки на [сайте Банка России](https://www.cbr.ru/hd_base/KeyRate/), внесите изменения в справочник на странице и установите дату «Ставки проверены по дату». Правила расчета после 2026 года требуют отдельного обновления сайта: приложение блокирует такие даты.

Сайт считает выплаты по самым ранним обязательствам; предоплаты, которые нельзя распределить на уже наступившие обязательства, показываются как ошибка для ручной проверки. Перед отправкой документов необходимо сверить суммы с квитанциями и платежными документами, а также проверить применимость моратория 2022 года и исковую давность.

## Проверка кода

Для проверки расчетной логики при наличии Node.js: `npm test`.

Библиотека JSZip включена локально в `vendor/` на условиях лицензии, приложенной рядом с ней.
